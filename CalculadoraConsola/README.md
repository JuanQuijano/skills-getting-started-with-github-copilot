# Calculadora Simple de Consola

Un proyecto sencillo de .NET que implementa una calculadora de consola con operaciones básicas.

## Características

- Suma (+)
- Resta (-)
- Multiplicación (*)
- División (/)
- Validación de división por cero
- Manejo de errores para entradas inválidas
- Interfaz en español

## Requisitos

- .NET SDK 10.0 o superior

## Cómo ejecutar

1. Navega al directorio del proyecto:
```bash
cd CalculadoraConsola/CalculadoraConsola
```

2. Ejecuta la aplicación:
```bash
dotnet run
```

## Cómo compilar

Para compilar el proyecto:
```bash
cd CalculadoraConsola/CalculadoraConsola
dotnet build
```

## Uso

1. Ejecuta la aplicación
2. Ingresa el primer número
3. Ingresa la operación deseada (+, -, *, /)
4. Ingresa el segundo número
5. El resultado se mostrará en pantalla
6. Puedes realizar otra operación o salir

## Ejemplo de uso

```
=================================
  Calculadora Simple de Consola
=================================

Ingrese el primer número: 10
Ingrese la operación (+, -, *, /): +
Ingrese el segundo número: 5

Resultado: 10 + 5 = 15

¿Desea realizar otra operación? (s/n): n

¡Gracias por usar la calculadora!
```
